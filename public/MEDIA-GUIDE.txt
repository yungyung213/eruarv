ERU Archive V9 — 등록 방법과 반영 여부

배포: ZIP 압축 해제 후 index.html이 바로 들어 있는 폴더 전체를 Netlify에 올립니다.

요청 반영 O/X
1 O 리스트 보기 삭제 (모바일 1열/2열 유지)
2 O 상세를 닫지 않고 이전/다음 게시물 이동. 사진 화살표는 같은 게시물 안에서만 이동.
    키보드 좌우와 모바일 이미지 스와이프 지원. 동영상 터치는 재생 컨트롤로 사용.
3 O 이미지/GIF/동영상 표시 지원. 상세 동영상은 수동 재생, 닫기/전환 시 정지.
    이 사이트에는 관리자 업로드 서버가 없습니다. 아래 파일 등록 방식으로 사용합니다.
4 O 메인 미디어 표시 및 이미지/GIF/동영상 교체 지원. 현재 기존 사진을 표시합니다.
5 X 지정 곡 실제 재생: YouTube 테스트에서 '이 동영상은 볼 수 없습니다' 표시.
    O 페이지 하단 제목/재생/정지 바. 외부 페이지로 이동하지 않음.
    브라우저 정책으로 소리 자동재생은 보장할 수 없습니다.
    메뉴 main/gallery 전환은 같은 문서에서 처리해 음악 엔진과 재생 시간을 유지합니다.
    새로고침/새 탭/직접 URL 이동은 새로운 문서이므로 다시 로딩됩니다.

갤러리 등록
- 파일을 images/ 또는 media/ 폴더에 넣습니다. media/는 직접 만들어도 됩니다.
- js/photos.js의 photos 배열에 게시물을 추가하고 images 배열에 아래처럼 파일을 나열합니다.
- 기존 images 속성명을 그대로 사용하며 한 게시물에 여러 형식을 섞을 수 있습니다.

{
  id: '2026-11-02-example',
  date: '2026-11-02',
  images: [
    {src: 'images/example.jpg', alt: '사진 설명'},
    {src: 'images/animation.gif', alt: 'GIF 설명'},
    {src: 'media/movie.mp4', type: 'video', poster: 'images/movie-cover.jpg', alt: '영상 설명'}
  ],
  genre: 'LDS', other: ['ERU'], colors: ['#000000'], thxTo: ''
}

- 동영상은 MP4(H.264/AAC)를 권장합니다. WebM도 브라우저에서 지원하면 재생됩니다.
- MOV는 확장자를 인식해도 코덱/기기에 따라 재생되지 않을 수 있으니 MP4로 변환하세요.
- 동영상 poster는 선택 사항입니다. 지정하면 목록 표지가 안정적으로 표시됩니다.
- GIF는 원본 그대로 사용하므로 애니메이션이 유지됩니다. 자동 압축/변환하지 않습니다.
- 새 사진은 기존 PNG 파생 이미지 목록에 없으면 원본 그대로 표시됩니다.
- 썸네일은 게시물의 첫 번째 미디어를 사용합니다. 기존 카테고리/캐릭터 필터 목록은
  gallery.html에서 관리합니다. 새 항목을 등록하면 해당 필터 버튼도 추가하세요.

메인 등록
js/site-config.js의 mainMedia 배열을 수정합니다.
export const mainMedia=[
  {src:'images/example.jpg',type:'image',alt:'사진'},
  {src:'images/animation.gif',type:'image',alt:'GIF'},
  {src:'media/movie.mp4',type:'video',poster:'images/movie-cover.jpg',alt:'동영상'}
];
여러 개를 등록하면 좌우 버튼이 나타납니다. 동영상은 음소거 자동재생을 시도하며
반복됩니다. 브라우저가 차단한 경우 동영상 자체 재생 컨트롤을 사용할 수 있습니다.

음악
js/music-config.js에서 youtubeId를 교체할 수 있습니다.
직접 음원이 있으면 audioSrc에 파일 경로, title에 제목을 입력하고 파일도 추가하세요.
직접 음원을 쓰려면 파일과 사용 가능한 음원인지 확인 후 별도 오디오 플레이어로 교체해야 합니다.
YouTube에서 음원을 다운로드하거나 추출하지 않았습니다.

검증
실제 게시물 이미지 표시 / 상세 사진 간 이동 / 다음 게시물 버튼 확인.
배포에서 제외한 임시 GIF 및 MP4로 갤러리 상세/메인 로드 확인(MP4 readyState=4).
지정 음악의 실제 재생은 실패함을 확인하고 오류 안내/외부 링크 제공.
